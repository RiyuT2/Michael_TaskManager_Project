A simple Laravel-based Personal Task Manager for managing tasks.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
- Set Due Date

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- JavaScript

## Database

This project uses MySQL through XAMPP/phpMyAdmin.

## How to Run

1. Clone the repository.
2. Run `composer install`.
3. Create `.env` from `.env.example`.
4. Configure the MySQL database.
5. Run `php artisan migrate`.
6. Run `php artisan serve`.
7. Open `http://127.0.0.1:8000`.
